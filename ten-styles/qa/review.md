# QA: «Один круг — десять стилей»

Как проверялось:
- Styleframes — кадры удержания каждой сцены, отрендеренные из того же кода (`planning/styleframes/`).
- Превью 960×540 целиком: кадры каждые 0,5 с (`scripts/extract_frames.py`) и контактные листы.
- Окна всех 11 переходов — каждый второй кадр; сцены с быстрым движением (баухаус, конструктивизм,
  поп-арт, мемфис, ретровейв, финал) — каждый 2–3 кадр.
- Звук — измерения: громкость BS.1770 (`ffmpeg ebur128`), истинный пик, баланс по октавам,
  атаки на сетке кадров (`scripts/audio_report.py`), спектрограмма.
- Ограничения: ролик не просмотрен в реальном времени и звук не прослушан — в среде нет вывода
  видео и звука. Скорость и плавность оценены по плотным последовательностям кадров.

## Оставшиеся ограничения
- Звук не прослушан и видео не просмотрено в реальном времени — только измерения и кадры.
- HUD набран 19 px: на телефоне это декоративная строка, главное название стиля крупно в каждой сцене.
- Первый кадр ролика тёмный (фраза выезжает с 1-го кадра); для обложки лучше взять кадр финальной сетки.
- Музыка синтетическая, без живых инструментов; для коммерческого релиза её можно заменить треком
  с тем же темпом 128,57 BPM — сетка склеек сохранится.
