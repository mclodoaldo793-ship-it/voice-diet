# Один круг — десять стилей

Динамичный 2D-ролик 1920×1080, 30 fps, 24 секунды, 128,57 BPM. Одна и та же форма — круг — проходит через десять
дизайн-стилей: ар-деко, баухаус, конструктивизм, швейцарский стиль, поп-арт, психоделия, мемфис, Y2K,
ретровейв и глитч. У каждого стиля свой свет, своя типографика, свой характер движения и свой переход.

- Ролик: `renders/final.mp4` (1920×1080, со звуком), превью `renders/preview.mp4` (960×540); версия без звука — командой из `SETUP.txt`
- Замысел: `planning/brief.md`, `planning/concept.md`, `planning/storyboard.md`, `planning/audio-map.md`
- Кадры-образцы сцен: `planning/styleframes/`
- Проверка: `qa/review.md`
- Команды и окружение: `SETUP.txt`

## Устройство
- `src/lib/timeline.ts` — тайминг (128,57 BPM: доля = 14 кадров, такт = 56 кадров = сцена), окна и типы переходов
- `src/scenes/` — интро, десять сцен и финал; каждая сцена — отдельная композиция в Studio
- `src/components/Transitions.tsx` — 11 переходов (маски, свет поверх)
- `src/components/Hud.tsx` — общая рамка: номер, стиль, десятилетие, прогресс
- `src/components/Camera.tsx` — наезды и удары камеры в долю
- `scripts/motion_energy.py` — измерение динамики по кадрам без просмотра
- `scripts/make_audio.py` — синтез саундтрека по тем же кадрам
