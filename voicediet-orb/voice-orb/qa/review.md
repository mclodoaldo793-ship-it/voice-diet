# QA: анимация VoiceDiet Orb

Проверки — по кадрам PNG (без потерь), метрикам разницы кадров и функциональному тесту в Chromium
(Playwright, программный WebGL SwiftShader). Видео в реальном времени глазами не просматривалось:
движение оценивалось по последовательностям кадров и численно.

## Проверки

- Силуэт и материалы: кадр t = 0 совпадает с `renders/threejs_ref_view.png` (та же модель и шейдеры). Деформация ≤ ±1.2 % в ожидании, ≤ ~5 % при громкой речи; силуэт узнаваем во всех состояниях (контактные листы).
- Пересечения сетки: невозможны по построению (только радиальный масштаб, одинаковый вдоль луча; гладкое поле, длина волны ≫ шага решётки). Изломов в кадрах не найдено.
- Скачки освещения: блики ядра привязаны к камере; меняется только окраска (плавно) и усиление ореола (пружина).
- Функциональный тест (`scripts/test.mjs`, вьюпорт 390×844 @3x): переключение состояний, авто-возврат из «готово», плашка тестового сигнала, пауза при скрытой вкладке и возобновление без скачка времени, упрощённое движение, `dispose()` удаляет canvas, теряет WebGL-контекст и останавливает цикл, ошибок в консоли нет.
- Решётка: найдено 12 пятиугольных узлов, 30 рёбер, 942 точки на рёбрах (30 × 31 + 12) — совпадает с икосферой 5 уровней.

## Ограничения

- Производительность на реальном телефоне не измерялась: в контейнере только программный WebGL (17 кадр/с на 1170×2532 px — это оценка снизу). Нагрузка: 1 сфера (16 128 треугольников) + 10 242 точки, без постобработки.
- Микрофон в контейнере недоступен: проверен путь тестового сигнала и `setAudioLevel`; код Web Audio стандартный, но вживую не прослушан.
- Импульсы намеренно сдержанные: при уменьшенном превью (< 400 px) в ожидании они едва заметны. Для обработки яркость ×1.4. Регулируется `pulseIntensity`.
- Вращение ядра — прецессия окраски, а не полный оборот: полный оборот с этой моделью меняет вид ядра (освещение в макете — matcap, привязано к камере).
- Задняя половина оболочки по-прежнему реконструирована предположительно (см. `../README.md`); импульсы туда не заходят.
